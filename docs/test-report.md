## 1. Thống kê tổng quan
* **Tổng số test case đã chạy thực tế:** 10
* **Kết quả chạy kiểm thử (Trước khi sửa bug):** 7 PASS / 3 FAIL (`TC-06`, `TC-07`, `TC-08`)
* **Kết quả sau khi sửa lỗi (Chặng 4):** 10 PASS / 0 FAIL
* **Độ phủ 5 loại kiểm thử bắt buộc:** Đủ 5/5 loại:

  2. **Giá trị biên (Boundary Value):** `TC-02` (biên dưới hợp lệ), `TC-03` (dưới biên dưới), `TC-06` (vượt biên trên 500 ký tự)
